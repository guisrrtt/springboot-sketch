# Sobre o projeto

Projeto demonstrando a criação de um serviço web para gerenciamento de pedidos, produtos, categorias e usuários. 
O objetivo do projeto é aplicar boas práticas de desenvolvimento backend, estruturação em camadas lógicas e mapeamento objeto-relacional (ORM) com **JPA / Hibernate**.
